Havn: A local-first, privacy-preserving personal data platform for finding cross-service correlations.

## Features

- Clean, modern Python 3.10+ implementation.
- Typed signatures and robust error handling.
- Comprehensive unit test coverage.

## Installation & Usage

```bash
git clone https://github.com/Raj123-0/havn.git
cd havn
python "backend/connectors/__init__.py" --help
```

## Testing

```bash
pytest tests/
```
